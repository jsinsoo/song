2. 파일 저장·불러오기 코드
먼저 song을 JSON 파일에 저장하고, 다시 loaded로 읽습니다. 이후 모든 문항은 loaded를 사용합니다.
브라우저의 HTML은 파이썬 코드를 직접 실행하지 않습니다. 내려받은 .py를 Python에서 실행하면 song_output.txt가 생성됩니다.
채점 및 결과 저장
각 문항의 출력 결과 네 줄을 입력하세요. 줄 앞뒤 공백과 빈 줄은 채점 시 무시하며, 가사 내부 문자와 순서는 정확히 비교합니다.
교육용 오프라인 HTML · 파일 저장은 브라우저의 다운로드 기능을 사용합니다.
